# FIT MASTER v0.5

Мобильное PWA-приложение для планирования занятий в тренажёрном зале и бассейне. После первой загрузки по HTTPS ресурсы кешируются и приложение может открываться офлайн. Данные хранятся локально в браузере устройства.

## Новое в v0.5

- Конструктор персональной программы на 2 или 3 тренировочных дня.
- Добавление и удаление упражнений в каждом дне с локальным сохранением.
- Журнал фактических подходов, повторений и рабочего веса по упражнениям.
- Таймер отдыха на 90 секунд с запуском, паузой и сбросом.
- История силовых тренировок, счётчик подходов и график введённых рабочих весов с фильтром по мышечным группам.
- Локальные SVG-иллюстрации тренажёров в папке `assets/`; внешние CDN, шрифты и API не используются.
- Сохранены библиотека упражнений, поиск и фильтры, избранное, анатомическая карта, схематичная анимация техники и дневник самочувствия из v0.4.

## Публикация / обновление GitHub Pages

1. Распакуйте `FIT-MASTER-v0.5.zip`.
2. Откройте репозиторий GitHub, где размещена предыдущая версия.
3. Загрузите **содержимое папки `fit-master`** в корень репозитория, сохранив папку `assets` и три SVG-файла внутри неё. Не загружайте только отдельные HTML/CSS/JS-файлы без `assets`.
4. Подтвердите замену существующих файлов.
5. В **Settings → Pages** проверьте источник публикации: ветка `main`, папка `/ (root)` (если проект публикуется из корня).
6. Дождитесь успешного GitHub Pages deployment и откройте опубликованный адрес.
7. Обновите страницу на телефоне. Service Worker использует новый кеш `fit-master-v5`. Если старая версия осталась, закройте PWA, откройте сайт онлайн и перезагрузите страницу; после активации нового кеша можно снова перейти в офлайн.

## Локальная проверка

Откройте `index.html` для проверки интерфейса. Для Service Worker нужен HTTPS или localhost. После первой загрузки дождитесь регистрации Service Worker, затем включите авиарежим и повторно откройте приложение.

## Данные и приватность

Избранное, конструктор, дневник самочувствия, программа на 2–3 дня и журнал тренировок сохраняются в `localStorage` текущего браузера. Данные не отправляются на сервер и не синхронизируются между устройствами. Очистка данных сайта может удалить записи; при необходимости заранее экспортируйте их вручную (экспорт пока не реализован).

## Медицинское ограничение

FIT MASTER — справочник и дневник, а не медицинское назначение. Упражнения отобраны с целью избегать выраженной прямой нагрузки на поясницу, осевой компрессии, глубоких наклонов и скручиваний, но это не гарантирует индивидуальную безопасность. При усилении боли, распространении боли по ноге, онемении или слабости прекратите движение и обсудите нагрузку с врачом/физиотерапевтом. При новой или нарастающей слабости ноги, онемении промежности либо нарушении мочеиспускания/дефекации требуется срочная медицинская помощь.

## Файлы

- `index.html` — интерфейс.
- `styles.css` — адаптивная тёмная тема.
- `app.js` — библиотека, навигация, планирование, таймер, журнал и график.
- `sw.js` — офлайн-кеш версии v0.5.
- `manifest.webmanifest`, `icon.svg` — установка PWA.
- `assets/*.svg` — локальные векторные иллюстрации тренажёров.
