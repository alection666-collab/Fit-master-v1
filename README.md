# FIT MASTER v0.3

Мобильное PWA-приложение для планирования занятий в тренажёрном зале и бассейне, визуального изучения упражнений и локального дневника самочувствия.

## Что нового в v0.3

- Переработана библиотека: карточки с визуальной схемой целевой области мышц.
- 13 описаний упражнений и активностей: зал, бассейн и спокойная ходьба.
- Поиск по названию, мышцам и оборудованию; фильтры по типу активности и группе мышц.
- Подробная карточка упражнения: целевые и вспомогательные мышцы, оборудование, уровень, последовательность выполнения, настройка и ограничения.
- Сохранены разделы «Обзор», «Моя программа», «Библиотека», «Динамика» и локальный дневник самочувствия из v0.2.
- Обновлён Service Worker: кэш v3, предварительное сохранение файлов приложения и удаление устаревшего кэша.
- В проекте нет внешних библиотек, CDN, веб-шрифтов или удалённых изображений. Схематичные иллюстрации встроены в код.

## Запуск локально

PWA и Service Worker требуют HTTPS или localhost. Для локального теста можно запустить простой сервер в папке `fit-master`:

```bash
python -m http.server 8000
```

Открой `http://localhost:8000`. Для автономного режима сначала открой приложение онлайн один раз, дождись завершения загрузки, затем проверь его после отключения сети. Открытие `index.html` напрямую через `file://` позволяет посмотреть интерфейс, но не активирует Service Worker.

## Публикация на GitHub Pages

1. Создай репозиторий, например `fit-master`.
2. Распакуй архив. Загрузи **содержимое папки `fit-master`** в корень репозитория: `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `README.md`.
3. На GitHub открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Дождись публикации GitHub Pages и открой выданный адрес. Для репозитория проекта адрес обычно имеет вид `https://<username>.github.io/<repository>/`.
7. Открой страницу на телефоне, дождись загрузки, затем добавь её на главный экран через меню браузера («Установить приложение» / «Добавить на главный экран»).

### Обновление существующего репозитория

1. Сохрани резервную копию текущих файлов или создай commit перед заменой.
2. Замени файлы в корне репозитория содержимым этой версии.
3. Проверь, что `sw.js` и `index.html` лежат в одной папке, а в `sw.js` задан новый cache key `fit-master-v3`.
4. Сделай commit и push в ветку, выбранную в настройках Pages.
5. После публикации открой приложение с интернетом и перезагрузи страницу. Новый Service Worker установит кэш v3 и удалит кэш предыдущей версии. Если браузер продолжает показывать старую версию, закрой установленное приложение и открой опубликованный адрес ещё раз.

## Хранение данных

Отметки самочувствия сохраняются в `localStorage` браузера на конкретном устройстве и в рамках домена. Они не синхронизируются между устройствами и не отправляются на сервер. Очистка данных сайта/браузера может удалить записи; при необходимости сохраняй резервные копии самостоятельно.

## Важная информация о здоровье

FIT MASTER — справочник и дневник, а не медицинская рекомендация или средство диагностики. У пользователя есть множественные грыжи пояснично-крестцового отдела и боль с распространением в ногу. Поэтому в подборке не предусмотрены упражнения с выраженной осевой нагрузкой, тяжёлой стабилизацией корпуса, глубокими наклонами и скручиваниями. Даже варианты с опорой и занятия в воде не являются гарантированно безопасными: индивидуальная переносимость различается. Новые упражнения, диапазон движений и нагрузку необходимо согласовать с врачом или физиотерапевтом. Прекрати движение при усилении боли, распространении симптомов по ноге, онемении или слабости. Новая/нарастающая слабость, онемение в области промежности или нарушение мочеиспускания/контроля кишечника требуют срочной медицинской помощи.

## Проверки версии

- JavaScript проверен на синтаксические ошибки (`node --check`).
- Все ресурсы приложения локальные; внешние URL в HTML/CSS/JS отсутствуют.
- Service Worker использует версионированный кэш и локальный fallback на `index.html`.
- Адаптивная сетка предусмотрена для широких экранов и смартфонов.

Полное тестирование установки на реальных устройствах и браузерах следует выполнить после публикации на HTTPS.
