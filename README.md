# FIT MASTER

Первая автономная PWA-версия дневника тренировок для зала и бассейна.

## Запуск локально
Откройте `index.html` в браузере. Для установки PWA и гарантированной работы Service Worker нужен HTTPS-хостинг (например, GitHub Pages) или локальный сервер.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий `fit-master`.
2. Загрузите в корень репозитория все файлы и папку проекта.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите Save.
5. После публикации откройте выданный GitHub Pages URL один раз онлайн. Затем приложение закеширует основные файлы и будет доступно офлайн.

## Что работает
- адаптивный интерфейс для телефона и компьютера;
- разделы «Обзор», «Моя программа», «Библиотека», «Динамика»;
- поиск и фильтр справочника;
- дневник боли и самочувствия с сохранением в localStorage;
- автономный кеш через Service Worker;
- установка на главный экран как PWA.

## Медицинская безопасность
Приложение не назначает персональные упражнения и не утверждает, что конкретное движение безопасно при грыже. При нескольких пояснично-крестцовых грыжах и боли с распространением в ногу нагрузку необходимо согласовать с врачом/физиотерапевтом. Срочная медицинская оценка нужна при новой/нарастающей слабости ноги, онемении в области промежности, нарушении мочеиспускания или контроля кишечника.

## Следующий этап
После получения рекомендаций специалиста можно добавить персональные тренировки с ограничениями по движениям, интенсивности, длительности и правилам остановки.
