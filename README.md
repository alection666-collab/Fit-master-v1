# FIT MASTER v0.5

Мобильное PWA-приложение для ведения занятий в тренажёрном зале и бассейне. Исходная база — архив `FIT-MASTER-v0.4.zip`; функции планирования и журнала добавлены поверх неё. Интерфейс, иллюстрации и изображения оборудования хранятся в архиве локально. Внешние CDN, веб-шрифты, удалённые изображения и сетевые API приложению не нужны.

## Что добавлено в v0.5

- Упрощённая навигация без экранов «Обзор», «План» и «Библиотека»: четыре раздела — «Тренировка», «Упражнения», «Тренажёры», «Прогресс». Пример недельной структуры свёрнут, чтобы не перегружать главный экран.
- Персональный конструктор программы на 2 или 3 тренировочных дня с отдельным списком упражнений для каждого дня.
- Автосохранение изменений программы на устройстве и отдельная кнопка сохранения.
- Журнал фактической тренировки: упражнение, число подходов, повторений и рабочий вес.
- Таймер подхода (30 / 45 / 60 секунд) и отдыха (60 / 90 / 120 секунд), с запуском, паузой и сбросом. Таймер рассчитан на работу в открытом приложении; фоновые системные уведомления не реализованы.
- История тренировочных сессий и график рабочего веса с фильтром по группам мышц. На графике каждая линия соответствует отдельному упражнению; сравнивай значения внутри одного и того же упражнения, а не между разными тренажёрами.
- Реалистичные AI-сгенерированные иллюстрации тренажёра тяги с опорой грудью, разгибания ног и подъёма на носки сидя в отдельном разделе «Тренажёры». Это визуальные ориентиры, не фотографии конкретных моделей и не рекомендация выполнять каждое показанное движение.
- Более подробные локальные SVG-схемы мышц спереди и сзади с подписями основных групп.
- Сохранены функции v0.4: библиотека упражнений, поиск и фильтры, избранное, анатомическая карта, схематичная анимация техники, конструктор личного списка, дневник самочувствия и локальное хранение данных.
- Обновлён Service Worker: все изображения и SVG входят в предварительный офлайн-кеш. Новый cache key — `fit-master-v5-r2`.

## Публикация или обновление GitHub Pages

1. Скачай `FIT-MASTER-v0.5.zip` и распакуй его.
2. Внутри архива открой папку `fit-master`.
3. Открой свой GitHub-репозиторий приложения.
4. Загрузи **всё содержимое папки `fit-master` в корень репозитория**. Не загружай только HTML/CSS/JS отдельно.
5. Обязательно сохрани структуру папок:
   - `assets/anatomy/anatomy-front.svg`
   - `assets/anatomy/anatomy-back.svg`
   - `assets/machines/leg-extension.jpg`
   - `assets/machines/seated-calf-raise.jpg`
   - `assets/machines/chest-supported-row.jpg`
   - три существующих SVG в `assets/`.
6. Подтверди замену файлов и создай commit в ветке `main`.
7. В GitHub открой **Settings → Pages**. Для публикации из корня должна быть выбрана ветка `main` и папка `/ (root)`. Если в проекте используется другая схема Pages, загружай содержимое в настроенную папку, не меняя относительные пути внутри `fit-master`.
8. Открой **Actions** и дождись успешного завершения процесса GitHub Pages deployment.
9. Открой опубликованный адрес сайта **онлайн** один раз и дождись загрузки страницы. Новый Service Worker (`fit-master-v5-r2`) должен установить локальные файлы и заменить предыдущий кеш `fit-master-*`.
10. На телефоне обнови страницу сайта. Если приложение уже установлено как PWA, закрой его полностью и открой снова после успешной онлайн-загрузки новой версии.
11. Для проверки автономности дождись окончания загрузки, затем включи авиарежим и снова открой приложение. Проверь фотографии, анатомические схемы, библиотеку и основные разделы.

### Если после обновления показывается старая версия

- Сначала проверь, что последний deployment в GitHub Actions завершился успешно.
- Открой сайт в обычном браузере с интернетом, обнови страницу и подожди активации Service Worker.
- Полностью закрой установленное PWA и открой снова.
- Не удаляй данные сайта без необходимости: дневник, избранное и тренировочные записи находятся в локальном хранилище браузера.

## Локальный запуск и офлайн-режим

- Для просмотра интерфейса можно открыть `index.html` напрямую.
- Для установки PWA и Service Worker нужен HTTPS (GitHub Pages подходит) или локальный сервер на `localhost`.
- При первой установке приложение должно один раз загрузить страницу и локальные ресурсы онлайн. После успешной установки Service Worker кеширует HTML, CSS, JS, иконку, фото и анатомические SVG.
- Если установка Service Worker не удалась или какой-либо файл отсутствует, полный офлайн-режим не гарантируется.

## Данные и приватность

Избранное, конструктор личного списка, программа на 2–3 дня, журнал тренировок и дневник самочувствия сохраняются в `localStorage` текущего браузера. Данные не отправляются на сервер и не синхронизируются между устройствами. Очистка данных сайта может удалить записи. Экспорт/импорт резервной копии в этой версии не реализован.

## Медицинское ограничение

FIT MASTER — справочник и дневник, а не медицинское назначение. Программа ориентирована на движения с опорой и без выраженной прямой нагрузки на поясницу; она не включает тяжёлую осевую нагрузку, глубокие наклоны, скручивания и упражнения, требующие интенсивной стабилизации корпуса. Это не гарантирует индивидуальную безопасность: даже сидячие тренажёры и упражнения в воде могут не подойти конкретному человеку. При усилении боли, распространении боли дальше по ноге, онемении или слабости прекрати упражнение/активность и согласуй индивидуальные ограничения с врачом или физиотерапевтом. При новой или нарастающей слабости ноги, онемении промежности либо нарушении мочеиспускания/дефекации требуется срочная медицинская помощь.

Анатомические изображения — условные учебные схемы основных мышечных групп, а не медицинский атлас и не инструмент диагностики.

## Состав проекта

- `index.html` — интерфейс приложения.
- `styles.css` — адаптивная тёмная тема.
- `app.js` — библиотека упражнений, избранное, планирование, таймер, журнал и графики.
- `sw.js` — предварительное офлайн-кеширование локальных ресурсов.
- `manifest.webmanifest`, `icon.svg` — установка PWA.
- `assets/` — локальные SVG-иллюстрации, анатомические схемы и изображения тренажёров.

## Происхождение визуальных материалов

- Три изображения оборудования в `assets/machines/` созданы специально для проекта генеративной графикой; они стилизованы под реальные тренажёры, но не изображают подтверждённые модели конкретного производителя.
- `assets/anatomy/*.svg` — оригинальные векторные учебные схемы, созданные для FIT MASTER.
- Три базовых SVG-иллюстрации оборудования в `assets/` сохранены из предыдущей версии проекта.
