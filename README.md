# FIT MASTER v0.4

Мобильное PWA-приложение для ведения занятий в тренажёрном зале и бассейне. Интерфейс и ресурсы находятся локально; после первой загрузки приложение может открываться офлайн через Service Worker.

## Новое в v0.4

- Анимированная схематичная демонстрация движения в карточке упражнения.
- Переключаемая анатомическая карта: вид спереди / сзади.
- Избранные упражнения с локальным сохранением и фильтром.
- Конструктор персонального списка упражнений с добавлением и удалением; список сохраняется на устройстве.
- Обновлён кеш Service Worker (`fit-master-v4`), чтобы браузер загрузил новую версию ресурсов.
- Сохранены дневник самочувствия, библиотека, поиск, фильтры и недельная структура из v0.3.

## Публикация на GitHub Pages

1. Распакуйте архив.
2. Откройте репозиторий GitHub, в который публикуется приложение.
3. Загрузите **содержимое папки `fit-master`** в корень репозитория (не саму внешнюю папку-обёртку).
4. Подтвердите замену старых `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg` и `README.md`.
5. В GitHub откройте **Settings → Pages**. Выберите публикацию из ветки `main` и папки `/ (root)`, если Pages ещё не настроен.
6. Дождитесь завершения публикации и откройте адрес GitHub Pages.
7. На телефоне обновите страницу. Если отображается старая версия, закройте установленное PWA, перезагрузите страницу сайта и откройте снова: новая версия использует отдельный кеш `fit-master-v4`.

## Локальный запуск

Для проверки можно открыть `index.html`, однако Service Worker и полноценный офлайн-режим требуют публикации по HTTPS (например, GitHub Pages) или локального HTTP-сервера. После первого успешного открытия через HTTPS дождитесь регистрации Service Worker, затем проверьте запуск в авиарежиме.

## Данные и приватность

Дневник, избранное и список упражнений хранятся в `localStorage` браузера на текущем устройстве. Они не синхронизируются между устройствами и могут быть удалены при очистке данных сайта. Внешние CDN, шрифты и сетевые API не используются.

## Важное медицинское ограничение

Приложение — справочник и дневник, а не медицинское назначение. Упражнения отобраны с целью избегать выраженной прямой нагрузки на поясницу, однако это не гарантирует индивидуальную безопасность. При усилении боли, распространении боли по ноге, онемении или слабости прекратите движение и обсудите нагрузку с врачом/физиотерапевтом. При новой или нарастающей слабости ноги, онемении промежности либо нарушении мочеиспускания/дефекации требуется срочная медицинская помощь.

## Состав проекта

- `index.html` — интерфейс приложения.
- `styles.css` — адаптивная тёмная тема и анимации.
- `app.js` — библиотека упражнений, поиск, избранное, конструктор и дневник.
- `sw.js` — автономный кеш ресурсов.
- `manifest.webmanifest` — параметры установки PWA.
- `icon.svg` — иконка приложения.
