# FIT MASTER v0.3

Офлайн-PWA-каталог упражнений для тренажёрного зала и бассейна. Версия собрана на основе предоставленного архива `FIT-MASTER-v0.2.zip`.

## Что изменилось в v0.3

- Интерфейс перестроен вокруг каталога упражнений: основные экраны — **Каталог**, **Избранное**, **Дневник**. Отдельные экраны «Обзор», «План» и «Библиотека» не используются.
- Добавлены карточки упражнений с группой мышц, основными/дополнительными мышцами, оборудованием и кратким описанием.
- В карточке открывается подробная инструкция: настройка, пошаговая техника, ограничения и индивидуальная оговорка.
- Добавлены локальные оригинальные SVG-схемы тренажёров/движений и условные карты мышечных групп. Это иллюстрации, а не точные чертежи оборудования и не медицинские анатомические атласы.
- Добавлены поиск по названию, мышцам, оборудованию и описанию; фильтры по месту активности и группе мышц.
- Добавлено избранное с сохранением на устройстве.
- Дневник сохраняет отметку боли, самочувствие, отмеченные симптомы и заметку. Сохранён ключ предыдущей версии `fitmaster_checkins_v1`, поэтому старые записи v0.2 в том же браузере сохраняются.
- Добавлены PWA-иконки, обновлён Service Worker и предварительное кеширование локальных ресурсов.
- Убраны внешние шрифты, CDN, удалённые изображения и аналитика.

## Состав каталога

Приоритет: спина, ноги и руки. Дополнительные группы: грудь и плечи. Отдельная силовая работа на пресс не добавлена: типичные скручивания, подъёмы корпуса, планки и упражнения с выраженной стабилизацией туловища намеренно не включены.

В бассейне представлены только осторожные варианты общей активности: спокойная ходьба и небольшие движения руками. Они не объявляются безопасными для всех. Плавательные стили не предлагаются автоматически.

## Медицинские ограничения и важные предупреждения

FIT MASTER — справочная библиотека и локальный дневник, а не диагностическая система, лечебная программа или медицинское назначение. Ни одно движение не гарантированно безопасно при множественных грыжах пояснично-крестцового отдела и боли с распространением в ногу. Даже тренажёр с опорой может провоцировать симптомы из-за посадки, амплитуды, сопротивления или индивидуальных особенностей.

- При усилении боли, распространении боли дальше по ноге, онемении или слабости прекрати движение; не пытайся «продолжать через боль».
- Индивидуальные ограничения, допустимую амплитуду, положение тела и возвращение к нагрузке согласуй с врачом или физиотерапевтом.
- Новая/нарастающая слабость в ноге, онемение в области промежности, задержка/недержание мочи или потеря контроля кишечника требуют срочной медицинской оценки.
- Отметки в дневнике не рассчитывают диагноз, не выдают разрешение на тренировку и не заменяют консультацию специалиста.

## Запуск локально

Для простого просмотра можно открыть `index.html`. Для проверки установки PWA и Service Worker нужен локальный HTTPS-сервер или `localhost`.

Например, при установленном Python:

```bash
python -m http.server 8000
```

Открой `http://localhost:8000`.

## Публикация на GitHub Pages — пошагово

1. Распакуй архив `FIT-MASTER-v0.3.zip`.
2. Открой папку `fit-master` внутри архива.
3. Открой свой репозиторий GitHub, например `Fit-master-v1`.
4. В корне репозитория выбери **Add file → Upload files**.
5. Загрузи **содержимое** папки `fit-master` целиком: `index.html`, `app.js`, `exercises-data.js`, `exercises.json`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `README.md` и папку `assets` со всеми вложенными файлами. Не загружай только саму папку `fit-master` как единственную вложенную папку, если Pages настроен на `/(root)`.
6. Убедись, что GitHub сохранил структуру `assets/exercises/` и `assets/anatomy/`. Не переименовывай SVG и не перемещай их в корень.
7. Нажми **Commit changes**.
8. Открой **Settings → Pages**. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/(root)`, затем **Save**. Если у репозитория уже настроен GitHub Actions workflow для Pages, оставь действующий способ публикации и проверь успешное завершение workflow.
9. Дождись зелёного статуса публикации в **Actions → Pages build and deployment**.
10. Открой Pages URL онлайн один раз. Дождись, пока в верхней части приложения появится статус **«КЕШ ГОТОВ»**, затем перезагрузи страницу.
11. Установка на Android: меню Chrome → **Установить приложение** или **Добавить на главный экран**. На iPhone: открой сайт в Safari → **Поделиться** → **На экран «Домой»**.
12. Проверь каталог, открытие карточки, поиск, фильтры, избранное и дневник. После этого включи авиарежим и повтори проверку.

### Обновление уже существующего репозитория

- Перед заменой сохрани копию текущих файлов.
- Загрузи содержимое `fit-master` в корень репозитория с заменой одноимённых файлов и добавлением новых.
- Сохрани папку `assets` со всеми SVG/PNG.
- Сделай Commit changes и дождись успешной публикации Pages.
- В приложении новая версия Service Worker называется `fit-master-v03`; при следующем открытии браузер установит новый кеш и удалит старый кеш `fit-master-*`.
- Если приложение остаётся открытым во время публикации, полностью закрой вкладку/установленное PWA и открой снова после завершения deployment.

## Офлайн-работа и хранение данных

- Все скрипты, стили, иконки, карты мышц и иллюстрации находятся внутри архива.
- Service Worker заранее кеширует все перечисленные локальные ресурсы.
- В приложении нет ссылок на внешние изображения, шрифты, CDN или API.
- Избранное и дневник сохраняются в `localStorage` текущего браузера/устройства. Эти данные не синхронизируются между устройствами и могут быть удалены при очистке данных сайта.
- Для гарантированного офлайн-старта сначала открой приложение онлайн и дождись завершения Service Worker installation. Затем проверь в авиарежиме.

## Проверки сборки

В рамках подготовки выполнены автоматические проверки:

- синтаксис `app.js` и `exercises-data.js`;
- корректность JSON-манифеста и каталога;
- наличие всех локальных файлов, на которые ссылается приложение и Service Worker;
- отсутствие внешних URL в HTML/CSS/JS/манифесте/Service Worker;
- отсутствие повторяющихся HTML `id`;
- проверка структуры ZIP;
- логические smoke-тесты навигации, поиска, фильтров «Бассейн» и «Ноги», отображения избранного и сохранения записи дневника;
- проверка Service Worker: состав предварительного кеша, удаление старого кеша и резервная выдача `index.html` при офлайн-навигации;
- проверка адаптивных CSS-правил для узких экранов (до 650 px), планшетов и широких экранов.

Полноценный ручной тест установки и визуального поведения на реальных Android/iOS-устройствах не выполнялся в этой среде; headless-браузерный запуск был заблокирован окружением. Поэтому после публикации отдельно проверь первый онлайн-запуск, установку PWA, нижнюю мобильную навигацию и авиарежим на целевом телефоне.
